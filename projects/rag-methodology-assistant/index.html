AI Engineering · RAG

Index Methodology RAG Assistant

Answering “what's the cap rule for this index?” means searching dozens of 100-page methodology PDFs — slow, and a wrong answer ends up in a rebalancing file.

My role
Solo build — parsing, retrieval, evaluation set, and UI.

Approach

Layout-aware PDF parsing into Markdown, hybrid retrieval (BM25 + embeddings) with cross-encoder reranking, and answers that cite the exact page — or refuse when the rule isn't in the documents.

Results

On a hand-labelled set of 150 real analyst questions, the assistant answers 89% correctly with 96% of citations pointing to the right page. Hybrid retrieval beat embeddings-only by 11 points, and reranking added another 6. When the answer isn't in the documents it says so, which analysts trust more than a confident guess.

Technical highlights

  • 01Layout-aware chunking that keeps tables and rule clauses intact
  • 02Hybrid BM25 + dense retrieval, then cross-encoder reranking of the top 20
  • 03Answer only from retrieved context, with page citations — and an explicit “not found” path
  • 04Evaluated with the same harness as the agents: accuracy, citation precision, refusal rate
