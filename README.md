# Portfolio V2 — Hicham Alaoui

Editorial enterprise-AI style portfolio (white canvas, deep-green product bands, monumental display type) built with **Next.js 15 + Tailwind CSS 4** (TypeScript, App Router, static export).

## Features

- Monumental hero with typed role label + dark product console card
- Count-up metrics, reveal-on-scroll animations, scroll-spy nav
- **Case-study pages** for each featured project (`/projects/<slug>/`) with architecture diagrams
- **Project filtering** by category tag
- **Command palette** — press `Ctrl/Cmd + K` anywhere
- **Contact form** with validation (Formspree-ready, mailto fallback)
- SEO: sitemap.xml, robots.txt, Open Graph, JSON-LD structured data, favicon
- 404 page, back-to-top
